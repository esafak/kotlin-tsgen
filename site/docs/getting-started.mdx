kotlin-tsgen is published to [Maven Central](https://search.maven.org/search?q=g:io.github.esafak.kotlintsgen).

Be sure to apply the [Kotlinx Serialization](https://github.com/Kotlin/kotlinx.serialization) plugin.

### Adding a dependency

<!-- [//]: # (@formatter:off) -->

  values={[
    { label: 'Gradle Kotlin DSL', value: 'kts', },

<TabItem value="kts">

<VersionedCodeBlock language="kotlin">{({latestRelease, kotlinVersion}) => `plugins {
  kotlin("jvm") version "${kotlinVersion}"
  kotlin("plugin.serialization") version "${kotlinVersion}"
}

dependencies {
  implementation("io.github.esafak.kotlintsgen:kotlin-tsgen-core:${latestRelease}")
}`}</VersionedCodeBlock>

</TabItem>
<TabItem value="groovy">

<VersionedCodeBlock language="groovy">{({latestRelease, kotlinVersion}) => `plugins {
  id "org.jetbrains.kotlin.jvm" version "${kotlinVersion}"
  id "org.jetbrains.kotlin.plugin.serialization" version "${kotlinVersion}"
}

dependencies {
  implementation("io.github.esafak.kotlintsgen:kotlin-tsgen-core:${latestRelease}")
}`}</VersionedCodeBlock>

</TabItem>
<TabItem value="maven">

:::info

Maven must postfix the module name with the target variant, for example: `-jvm`

:::

<VersionedCodeBlock language="xml">{({latestRelease}) => `<dependency>
  <groupId>io.github.esafak.kotlintsgen</groupId>
  <artifactId>kotlin-tsgen-core-jvm</artifactId>
  <version>${latestRelease}</version>
</dependency>`}</VersionedCodeBlock>

</TabItem>
</Tabs>
