kotlin-tsgen is published to [Maven Central](https://search.maven.org/search?q=g:io.github.esafak.kotlintsgen).

Be sure to apply the [Kotlinx Serialization](https://github.com/Kotlin/kotlinx.serialization) plugin.

### Adding a dependency

<TabItem value="kts">

```kts
plugins {
  kotlin("jvm") version "2.3.0"
  kotlin("plugin.serialization") version "2.3.0"
}

dependencies {
  implementation("io.github.esafak.kotlintsgen:kotlin-tsgen-core:0.2.5")
}
```

</TabItem>
<TabItem value="groovy">

```groovy
plugins {
  id "org.jetbrains.kotlin.jvm" version "2.3.0"
  id "org.jetbrains.kotlin.plugin.serialization" version "2.3.0"
}

dependencies {
  implementation("io.github.esafak.kotlintsgen:kotlin-tsgen-core:0.2.5")
}
```

</TabItem>
<TabItem value="maven">

:::info

Maven must postfix the module name with the target variant, for example: `-jvm`

:::

```xml
<dependency>
  <groupId>io.github.esafak.kotlintsgen</groupId>
  <artifactId>kotlin-tsgen-core-jvm</artifactId>
  <version>0.2.5</version>
</dependency>
```

</TabItem>
</Tabs>
